Entry for the [make.fun bounty "The Vacuum's Alibi: One Line, 200 Characters"](https://make.fun/competitions/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7): a program that writes the funniest one-line excuse a robot vacuum can give for missing a spot, 200 characters or fewer.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader). Pure TypeScript, Node built-ins only, no network, fully deterministic — every run writes the same bytes.
